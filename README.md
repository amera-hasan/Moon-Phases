# Moon-Phases
🌙 Interactive 3D simulation of the 8 lunar phases built with C++ and OpenGL/GLUT. Features real-time animation, texture mapping, lighting, and mouse interaction.

✨ Features 
- Real-time 3D simulation of all 8 moon phases
- Interactive phase selection via mouse click
- Camera control (rotate, zoom, reset)
- BMP texture loading for Earth and Moon surfaces
- 900-star background with varying brightness
- Phase preview panel with 2D lighting simulation
- Pause/Resume animation

🛠️ Built With 
- C++
- OpenGL
- FreeGLUT
- GLEW
- GLU
- Visual Studio
  
🎮 Controls
| Key | Action |
|-----|--------|
| Left Click | Select moon phase |
| Space | Pause / Resume |
| Arrow Keys | Rotate camera |
| + / - | Zoom in / out |
| R | Reset camera |
| ESC | Exit |
